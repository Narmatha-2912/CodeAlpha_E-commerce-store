# 🛍️ CodeAlpha – E-Commerce Store

A modern, responsive and user-friendly E-Commerce Web Application built using Django, SQLite, HTML, CSS and JavaScript.

## 🚀 Project Overview

This project is designed to provide customers with a smooth online shopping experience. Users can explore products, search for items, add products to their cart and manage their shopping activities.

## ✨ Key Features

✅ **1. User Authentication**

Secure user registration, login and logout functionality.

✅ **2. Product Catalog**

Display products with images, descriptions, prices and categories.

✅ **3. Product Search and Filtering**

Search products and filter items based on categories and prices.

✅ **4. Shopping Cart**

Add products to the cart, update quantities and remove unwanted items.

✅ **5. Wishlist**

Save favourite products for future purchases.

✅ **6. Checkout System**

Collect customer details and manage the checkout process.

✅ **7. Order Management**

View order details and track order history.

✅ **8. Admin Dashboard**

Manage products, categories, customers and orders through Django Admin.

✅ **9. Responsive User Interface**

A clean and modern design that works on desktops, tablets and mobile devices.

## 🛠️ Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Python, Django
- **Database:** SQLite
- **Tools:** VS Code, Git and GitHub

## ⚙️ Installation and Setup

**Step 1: Clone the Repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Navigate to the Project**

```bash
cd CodeAlpha_Ecommerce_Store
```

**Step 3: Create a Virtual Environment**

```bash
python -m venv venv
```

**Step 4: Activate the Environment**

```bash
venv\Scripts\activate
```

**Step 5: Install Dependencies**

```bash
pip install -r requirements.txt
```

**Step 6: Apply Database Migrations**

```bash
python manage.py migrate
```

**Step 7: Create an Admin Account**

```bash
python manage.py createsuperuser
```

**Step 8: Run the Application**

```bash
python manage.py runserver
```

**Step 9: Open in Browser**

```text
http://127.0.0.1:8000/
```

Admin Dashboard:

```text
http://127.0.0.1:8000/admin/
```
